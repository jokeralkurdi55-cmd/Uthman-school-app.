# تطبيق مدرسة عثمان بن عفان — Flutter starter

واجهة تأسيسية عربية RTL لاختيار نوع الحساب وصفحة أولية لتسجيل الدخول. هذه ليست نسخة إنتاجية: المصادقة وربط Firestore والصلاحيات الخادمية لم تُفعّل بعد، ولا تحفظ أي بيانات.

## إعداد المشروع
1. ثبّت Flutter SDK وAndroid Studio (ولبناء iOS يلزم macOS مع Xcode).
2. فك ضغط الحزمة وافتح المجلد كمشروع Flutter.
3. شغّل `flutter pub get`.
4. ثبّت Firebase CLI وFlutterFire CLI، ثم سجّل الدخول بنفس حساب Google المخوّل بإدارة مشروع المدرسة.
5. من مجلد المشروع شغّل `flutterfire configure --project=uthman-bin-affan-school` واختر Android و/أو iOS. ستُنشأ `lib/firebase_options.dart` وملفات المنصات اللازمة.
6. بعد مراجعة إعدادات Authentication وFirestore وقواعد الأمان، أضف تهيئة Firebase إلى `main()` وفعّل شاشات الدخول الفعلية.
